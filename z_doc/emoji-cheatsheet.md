## 🚀 提交类型 Emoji 表情包

### ✨ **feature** - 新特性
| Emoji | 含义            | 适用场景               |
|-------|---------------|--------------------|
| ✨     | 新特性 / 新功能     | 添加新的功能、特性、改善       |
| 🚀    | 功能上线 / 性能优化   | 推出新的功能，或者提升性能      |
| 🆕    | 新增功能          | 类似于✨，但更加专注于“新增”    |
| 📱    | 移动端功能         | 针对 App 移动端功能的新增或优化 |
| 🧪    | 实验性特性 / 新功能测试 | 用于实验性功能，尚未稳定可用     |

---

### 🐛 **bugfix** - Bug 修复
| Emoji | 含义                     | 适用场景              |
|-------|------------------------|-------------------|
| 🐛    | Bug 报错 / Bug 修复        | 修复已发现的 Bug，确保功能正常 |
| 🧯    | 紧急修复 / 火速灭火            | 火线补丁、Hotfix 提交    |
| 🧨    | 危险问题 / 崩溃风险修复          | 修复 crash、严重逻辑问题等  |
| 🚑    | 急救修复（俗称 ambulance fix） | 表示紧急、及时的补丁        |
| 🔧    | 小修小补 / 功能修整            | 非致命 bug、逻辑微调      |

---

### 🔨 **refactor** - 重构
| Emoji | 含义          | 适用场景              |
|-------|-------------|-------------------|
| 🔨    | 重构代码 / 工具变更 | 标准的重构提交，通常指代码结构改动 |
| 🛠    | 工具、依赖更新     | 调整工具、依赖版本、代码迁移    |
| 🧹    | 清理 / 重构清理   | 移除废弃代码、无用依赖等      |
| 🔧    | 小修小补 / 配置调整 | 修复小问题，改进代码可维护性    |

---

### 🧹 **chore** - 杂项工作
| Emoji | 含义        | 适用场景                  |
|-------|-----------|-----------------------|
| 🧹    | 清理、整理     | 清理代码、整理文件结构、移除不再使用的内容 |
| 📦    | 包装、打包     | 更新或修改构建配置、打包过程相关      |
| 🔧    | 配置、设置调整   | 更新配置文件、调整项目配置、工具配置    |
| 📝    | 文档更改      | 更新文档、改进 README、添加注释   |
| ⏳     | 性能优化      | 优化构建时间、减少代码冗余、提高效率    |
| 🔄    | 同步、更新     | 同步代码库、合并更改、更新依赖       |
| 🗂    | 文件/目录结构调整 | 重构文件、调整目录结构           |
